# Monster Codex

**Phase:** Phase 3 — OOP & Inheritance

Abstract Monster base class with GetEntry() overridden by CommonMonster and BossMonster. Keyword search across a List<Monster>.

## Concepts Practiced

- Abstract classes
- Polymorphism
- Contains() / ToLower()
- PadRight() / ToUpper()

## Highlights

- GetEntry() called polymorphically across a List<Monster> via foreach
- Keyword search uses Contains() and ToLower() on the full entry string
- PadRight() and ToUpper() applied for consistent display formatting

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
