# Battle Demo

**Phase:** Phase 3 — OOP & Inheritance

Console app with a Boss inheriting from Enemy and overriding TakeDamage() to take half damage with a phase change.

## Concepts Practiced

- Inheritance
- virtual / override
- : base()
- is operator
- HP phase threshold

## Highlights

- Boss inherits from Enemy and overrides TakeDamage() to take half damage
- Phase change triggers below an HP threshold
- Uses virtual, override, : base(), and is

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
