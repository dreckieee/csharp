# Task List

**Phase:** Phase 2 — Collections & Lists

Generic task manager using a TaskList<T> class with filtering via Predicate<T>.

## Concepts Practiced

- Generics
- List<T>
- Predicate<T>
- Lambda expressions

## Highlights

- TaskList<T> backed by a List<T> with Add(), Remove(), and FindAll()
- FindAll() with Predicate<T> filters tasks by completion status
- Demonstrates the difference between = (assignment) and == (comparison) inside lambdas
