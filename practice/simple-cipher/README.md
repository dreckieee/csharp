# Simple Cipher

**Phase:** Phase 1 — Fundamentals

Console app that encrypts and decrypts messages using a Caesar cipher.

## Concepts Practiced

- Char arithmetic
- Modulo wrapping
- char.IsLetter()
- char.IsUpper()

## Highlights

- Encrypts and decrypts using a shift value normalized with % 26
- Preserves casing and passes non-letter characters through unchanged
- Handles both encryption and decryption via a single parameterized method

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
