# Enemy Spawner

**Phase:** Phase 2 — Collections & Lists

Console app simulating an enemy list with a damage system. Enemies auto-remove at zero HP.

## Concepts Practiced

- List<T>
- FindAll()
- HP threshold filtering
- Type filtering

## Highlights

- Enemies take damage and auto-remove when HP reaches zero
- FindAll() filters by type and HP threshold

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
