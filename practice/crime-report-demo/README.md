# Crime Report Demo

**Phase:** Phase 3 — OOP & Inheritance

Console app managing suspects across three roles — Civilian, Criminal, and Witness — all inheriting from an abstract Suspect class.

## Concepts Practiced

- Abstract classes
- Multiple interfaces
- is pattern matching
- Enum

## Highlights

- ICriminal and IWitness enforce role-specific methods
- Interface detection at runtime via is pattern matching on a List<Suspect>
- Enum used for type-safe status values

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
