# Number Analyzer

**Phase:** Phase 1 — Fundamentals

Console app that finds the sum, average, highest, and lowest of n numbers.

## Concepts Practiced

- Arrays
- Multiple methods
- Full input validation

## Highlights

- Accepts n numbers and computes sum, average, highest, and lowest
- Logic split across multiple focused methods
- Full input validation on every entry

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
