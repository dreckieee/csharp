# Mini Character Card Generator

**Phase:** Phase 1 — Fundamentals

Console app that generates random RPG stats and calculates a power rating with a tier label.

## Concepts Practiced

- Type casting
- Convert.ToInt32()
- PadRight() / PadLeft()
- String arrays

## Highlights

- Generates randomized RPG stats using the Random class
- Calculates a power rating and assigns a tier label
- Uses PadRight() and PadLeft() for aligned column output

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
