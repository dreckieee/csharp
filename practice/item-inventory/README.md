# Item Inventory

**Phase:** Phase 2 — Collections & Lists

Console app managing an RPG item inventory with quantity tracking. Items auto-remove at zero stock.

## Concepts Practiced

- List<T>
- FindAll()
- Quantity decrement logic
- Auto-removal

## Highlights

- Items decrement on use and auto-remove when quantity reaches zero
- FindAll() used to rebuild the list on removal

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
