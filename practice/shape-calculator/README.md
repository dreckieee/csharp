# Shape Calculator

**Phase:** Phase 3 — OOP & Inheritance

Circle, Rectangle, and Triangle inherit from an abstract Shape class. A single foreach loop calls GetArea() polymorphically.

## Concepts Practiced

- Abstract classes
- Polymorphism
- foreach
- Method override

## Highlights

- Each shape overrides GetArea() with its own calculation
- A single foreach loop across a List<Shape> calls GetArea() on all types

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
