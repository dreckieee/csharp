# Turn-Based Battle

**Phase:** Phase 3 — OOP & Inheritance

Swordsman and Archer inherit from an abstract Fighter class. Turn order is randomized each round inside a while loop game loop.

## Concepts Practiced

- Abstract classes
- Method override
- Randomized turn order
- while loop game loop

## Highlights

- Each fighter overrides Attack() with different damage logic
- Turn order randomized each round — not fixed
- while loop drives the game loop until one fighter reaches zero HP

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
