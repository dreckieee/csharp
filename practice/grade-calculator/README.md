# Grade Calculator

**Phase:** Phase 1 — Fundamentals

Console app that averages n subject scores and outputs a final grade.

## Concepts Practiced

- for loops
- Decimal arithmetic
- Input validation

## Highlights

- Accepts n subject scores from user input
- Computes average and maps to a final grade using conditional logic

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
