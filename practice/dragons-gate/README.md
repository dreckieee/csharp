# Dragon's Gate

**Phase:** Phase 3 — OOP & Inheritance

Turn-based RPG battle where Hero and Dragon inherit from an abstract Character class. HP is clamped via a private backing field.

## Concepts Practiced

- Abstract classes
- Private backing field
- Math.Clamp()
- protected set
- DefenseMultiplier

## Highlights

- HP clamped with Math.Clamp() via a private backing field
- DefenseMultiplier property using protected set reduces incoming damage when the hero defends

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
