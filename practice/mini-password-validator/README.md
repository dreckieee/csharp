# Mini Password Validator

**Phase:** Phase 1 — Fundamentals

Console app that validates a password against three rules and loops until a valid entry or exit.

## Concepts Practiced

- String.Length
- Contains()
- char.IsDigit()
- foreach with bool flag

## Highlights

- Validates minimum 8 characters, no spaces, and at least one digit
- Uses char.IsDigit() inside a foreach loop with a bool flag
- Loops until a valid password is entered or the user exits

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
