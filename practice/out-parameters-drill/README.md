# Out Parameters Drill

**Phase:** Phase 1 — Fundamentals

Console app demonstrating out parameters through two focused methods.

## Concepts Practiced

- out parameters
- Random ranges
- Position-based mapping

## Highlights

- GenerateStats() writes HP, attack, and defense into out parameters using random ranges
- EvaluateF­ighter() calculates a total stat score and writes a rank (F/C/B/A) into an out parameter
- Variable names at the call site intentionally differ to reinforce position-based mapping

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
