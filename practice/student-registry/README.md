# Student Registry

**Phase:** Phase 2 — Collections & Lists

Console app managing a student list with pass/fail filtering and a computed property.

## Concepts Practiced

- List<T>
- FindAll()
- Computed properties
- Auto-calculated status

## Highlights

- Pass/fail status computed automatically via a property — not stored manually
- FindAll() used for filtering by status

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
