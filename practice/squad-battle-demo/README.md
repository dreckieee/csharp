# Squad Battle Demo

**Phase:** Phase 3 — OOP & Inheritance

RPG battle system with Warrior, Mage, and Archer inheriting from an abstract Unit class stored in a List<Unit>.

## Concepts Practiced

- Abstract classes
- Interfaces
- List<T> polymorphism
- Mana shield
- Critical hit chance

## Highlights

- Mage overrides TakeDamage() using Mana as a damage shield and implements IHealable
- Archer has a 30% critical hit chance
- All units stored in a List<Unit> — polymorphism drives combat

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
