# Party Manager

**Phase:** Phase 2 — Collections & Lists

Console app managing an RPG party using three classes with List<T> and lambda expressions.

## Concepts Practiced

- List<T>
- Lambda expressions
- Find()
- FindAll()
- Multiple classes

## Highlights

- Hero, Party, and Program split across three files
- Party encapsulates a List<Hero> — search and filter via Find() and FindAll() lambdas

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
