# Dice Roller

**Phase:** Phase 1 — Fundamentals

Console app that rolls three dice and awards prizes based on scoring tiers.

## Concepts Practiced

- Random class
- Conditional logic
- Doubles and triples detection

## Highlights

- Rolls three dice using the Random class
- Awards prizes based on doubles, triples, and scoring tiers

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
