# Grade Report System

**Phase:** Phase 1 — Fundamentals

Console app that calculates average grade and letter rating for n students with 5 scores each.

## Concepts Practiced

- 2D arrays
- Multiple methods
- Full input validation

## Highlights

- Accepts scores for n students across 5 subjects using 2D arrays
- Computes average and assigns letter rating per student
- Full input validation throughout

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
