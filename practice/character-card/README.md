# Character Card

**Phase:** Phase 2 — Collections & Lists

Introduces classes with a constructor, properties, and methods split across two files.

## Concepts Practiced

- Classes
- Constructors
- Properties
- Methods
- Two-file structure

## Highlights

- Character class with LevelUp(), TakeDamage(), and IsAlive() methods
- Properties use private set discipline enforced from day one
- Split across two files — Character.cs and Program.cs

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
