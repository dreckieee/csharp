# Student Roster
**Phase:** Phase 2 — Collections & Lists
Groups a seeded list of students by grade level using LINQ GroupBy, printing each group with names, student count, and average GWA.

## Concepts Practiced
- LINQ GroupBy and OrderBy
- IGrouping iteration
- Enum values cast to int for display
- Aggregates: Count() and Average() per group
- Shared static Random instance across methods

## Highlights
- 9 students across Grade 10, 11, and 12
- Groups ordered by grade level via enum integer values
- Average GWA per group formatted to 2 decimal places with :F2
- GradeLevel enum with explicit integer values (10, 11, 12) for clean cast output

## Rules Enforced
- 0 warnings before push
- One file per class
- private set on all Student properties
- Static utility class with no instantiation
- Variables declared at point of use
