# Damage Printer

**Phase:** Phase 1 — Fundamentals

Console app demonstrating method overloading through three versions of PrintDamage().

## Concepts Practiced

- Method overloading
- private set properties
- Crit multiplier logic

## Highlights

- Three overloads: damage only, damage with attacker name, damage with crit status
- Crit doubles damage — rolled once and stored before being passed in
- Fighter class uses private set on name and attack properties

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
