# Mini Phonebook

**Phase:** Phase 2 — Collections & Lists

Console app that looks up contacts by name using a Dictionary<string, string>.

## Concepts Practiced

- Dictionary<string, string>
- ContainsKey()
- ToLower()
- String formatting

## Highlights

- Direct key lookup using ContainsKey()
- Case-insensitive search via ToLower()
- First-letter capitalization applied on display output

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
