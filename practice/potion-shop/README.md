# Potion Shop

**Phase:** Phase 3 — OOP & Inheritance

Potion inventory system with two-tier interface inheritance — IPremiumPotion : IRegularPotion.

## Concepts Practiced

- Interface inheritance
- Abstract classes
- is pattern matching
- OrderBy() / OrderByDescending()

## Highlights

- IPremiumPotion inherits from IRegularPotion — two-tier interface chain
- Abstract Potion class serves as the shared base
- is pattern matching detects premium potions at runtime
- OrderBy() and OrderByDescending() handle inventory sorting

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
