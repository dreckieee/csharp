# Movie Watchlist

**Phase:** Phase 2 — Collections & Lists

Console app managing a movie list with watch status and rating filters.

## Concepts Practiced

- List<T>
- FindAll() lambdas
- Boolean toggle
- Filter logic

## Highlights

- Watch status toggled via a boolean flag on each movie object
- FindAll() with lambdas filters by watched status and rating thresholds

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
