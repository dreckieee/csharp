# RPG Class Selector

**Phase:** Phase 3 — OOP & Inheritance

Knight, Wizard, and Rogue inherit from an abstract Hero class. User input drives class instantiation via a switch statement.

## Concepts Practiced

- Abstract classes
- switch statement
- Polymorphism
- User-driven instantiation

## Highlights

- Each subclass overrides GetStats() with class-specific output
- Switch statement maps user input to the correct instantiation

## Rules Enforced

- 0 warnings before every push
- One file per class
- `private set` unless exposed writing is needed
- No unused variables or parameters
